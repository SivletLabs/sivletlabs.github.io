Architecture & Methodology

How JEV-Style System-1 Decisions Work

Autoregressive language models decode sequentially, token-by-token. For discrete decisions—such as agent tool selection, classification, and MDP action choices—this introduces 800ms+ latency, high cost, and uncalibrated probabilities. SivletLabs adopts the JEV paradigm: freezing state context in KV-cache and scoring all candidate actions in parallel in a single forward pass.

01

Prefix KV-Cache Rewinding

The observation state is ingested once. We freeze the prompt's key-value activations and rewind to the prompt boundary to score all candidate continuations in parallel—eliminating token decoding loops entirely:

Single Forward Scoring:
score(s, ck) → πθ ∈ ΔK-1
Prompt cached once · Zero sequential generation
Sub-15ms deterministic inference
02

Native Typed Primitives

Instead of unstructured text parsed with fragile regexes, the model natively emits typed decision primitives: discrete routing (choice), expected ordinal score (score), and calibrated boolean belief (noul):

Typed Primitives (JEV Protocol):
choice(K) · score(Ε[k]) · noul(ptrue)
Confidence = 1 − Normalized Entropy
Zero hallucination · Type-safe outputs
03

Strictly Proper Scoring Calibration

Softmax token distributions suffer from overconfidence. We train and benchmark under Gneiting & Raftery (2007) strictly proper scoring rules, mathematically penalizing miscalibrated epistemic uncertainty:

Proper Scoring Rule:
SBrier(p, y*) = −Σk (pk − 1[k=y*])2
Evaluated via Gymnasium harness (jev-eval)
