# 3. Standard Gymnasium interaction loop (12ms / step)
obs, info = env.reset(seed=42)

    obs, reward, terminated, truncated, info = env.step(action)

print(f"Goal: {info['at_goal']} | Return: {info['cumulative_reward']:+.2f}")
env.close()

  },
});

System-1 Decision Foundations & x402 Micropayment Loop

1. Problem Formulation: The System-1 Void

Modern autonomous agents waste substantial compute and latency by delegating discrete routing, approval gating, and tool-call pruning to autoregressive generative LLMs. Deciding whether a tool output should be kept does not require generating 50 text tokens; it requires evaluating a categorical posterior distribution πθ(a|s) in a single feedforward pass (≤15ms).

2. Strictly Proper Scoring Rewards

Standard hard 0-1 accuracy encourages overconfident mispredictions. In jev-eval, single-step contextual bandits utilize Strictly Proper Scoring Rules (Gneiting & Raftery, 2007) where the expected reward is strictly maximized if and only if the policy states the true calibrated probability distribution:

S_Brier(p, y*) = - ∑_{k=0}^{K-1} (p_k - I[k = y*])² ∈ [-2.0, 0.0]
